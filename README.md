# 诗雨 · Poem rain

窗口右下角有一朵云。每隔一会儿，它落下一行诗——从**你自己的文字**里随机抽。

## 它能做什么

- **拖动**：按住那朵云拖到窗口任意位置，松手记住；拖到左半边，句子自动翻到右边展开
- **用自己的文字**：设置 → 插件 → 诗雨 →「我的文字」，粘贴或从文件导入；每行一句，`句子｜出处` 会署名
- **三种声音**：静音 / 雨声 / **诗音**（把落下的这句话按五声音阶弹出来，一个字一个音）
- **颜色**：金 / 青 / 紫 / 粉 / 绿 / 白，影响云、尾句、按钮、面板边框
- **诗集**：「留」下来的句子攒在本地，最多 40 首

默认是**现场生成的原始版**——没导入任何文字时，它用内置词库现拼句子。导入之后只从你的文字里抽。

## 安装

```
Plugins → Add plugin → 粘贴本仓库地址或包名 dsh-poem-rain
```

或者从插件索引安装（见下）。

## 索引

本仓库的插件索引：<https://wangzimo-archive.pages.dev/plugins/index.json>

在 DSH 里：**Plugins → Discover → Add index source**，填上面这个 URL。

## 隐私

诗句、你的文字、收藏、位置、颜色，全部存在浏览器本地存储里。不联网、不上传、不同步。
