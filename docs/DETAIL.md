# 诗雨 · Poem rain

窗口右下角有一朵很小的云。每隔一段时间，它落下一行诗。

## 它能做什么

- **可以拖着走**：按住那朵云就能拖到窗口任意位置，松手记住；下次打开还在那儿。拖到左半边，落下的句子会自动翻到另一边，不会跑出屏幕。
- **自己落诗**：默认每 100 秒落一行，两行一处，停 9 秒后自己淡掉。
- **点云再落一句**：想立刻要一句，点一下那朵云。拖动不会误触发点击。
- **双击云打开诗集**：你点过「留」的句子会攒在这里，最近 40 首，存在浏览器本地。
- **随时暂停**：诗集面板底部有「暂停 / 继续」，暂停后不再自己落诗，点云仍然有效。

## 三种声音

面板底部那个按钮循环切换，设置页里也有三个按钮。

| 模式 | 是什么 |
|---|---|
| **静音**（默认） | 什么都不响 |
| **雨声** | 一阵 1.6 秒的小雨：粉化噪声 + 雨滴颗粒 + 78Hz 水汽 |
| **诗音** | **把落下的这句话弹出来**——每个汉字按字码落进五声音阶，一个字一个音，最后一个字收回主音 |

诗音是从《名字之歌》搬过来的同一套引擎：`字码 % 5` 选宫商角徵羽，`(字码 >> 3) % 2` 选高低八度，
字长决定时值（0.26–0.48 秒）。非汉字（标点、英文）不出声，最多取前 12 个字。

实测一句「伴随着潮来潮去」→ 7 个音，简谱 `2 5 5 2 6 2 1`，287→784→392→587→440→587→262 Hz，
每个音都有能量（−26 dBFS 上下），总长 2.42 秒。

## 雨声

落诗的时候会有一阵很小的雨，1.6 秒自己散掉。它不是音频文件——是 WebAudio 现场合成的：

- **远雨幕**：白噪声先做一次"粉化"（叠随机游走，比纯白噪更像雨），再走带通 1500 Hz / 高通 320 Hz / 低通 8200 Hz，0.1 秒起来、1.55 秒散掉
- **水汽**：一圈 78 Hz 降到 62 Hz 的正弦，很轻
- **雨滴**：9–16 个短促颗粒，带通频率 1.8–5.6 kHz、Q 值 3.2–7.2，各自随机时刻、12–42 毫秒长度

电平特意压得很低（离线渲染实测峰值 −14 dBFS、RMS −34 dBFS），是背景而不是提示音。
实测包络：`0-20ms −43 dB → 100-300ms −26 dB → 500-700ms −42 dB → 1.5s 后 −86 dB`，确实是"一阵雨"而不是一段循环噪声。

不想听就诗集面板底部点「雨 声 开」关掉，开关存在本地。


## 导入你自己的文字（给别人用的关键）

插件是**通用**的：它不认识"王子默"，只认识"一行一行的话"。

- **一键载入内置诗库**：设置页或面板里点「载入内置诗库」，把随包附带的 252 行诗写进你的词库（这是给作者自己用的捷径，别人不需要点）
- **在设置里导入**：设置 → 插件 → 诗雨 → **我的文字**，粘贴或从文件读取
- **在诗集面板里导入**：双击那朵云 → 底部 **我 的 文 字**，同一个输入框

格式很简单：**每行一句**。想标注出处就写成 `句子｜出处`（竖线也可以是半角 `|`），
落诗时会显示成 `——《出处》`。空行、重复行自动去掉；整句被书名号包着的会剥掉书名号。

导入之后：
- 落诗**只从你的文字里抽**，不再用内置诗库
- 清空你的文字就退回现场生成器（原始版）
- 文字存在浏览器本地（`poem-rain:lines:v1`），不上传、不同步、换机器就没了——这是有意的

---

## 内置诗库（默认）

**默认从你自己的诗里抽。** 建了一个提取器（`plugins/_extract_lines.mjs`）把主站诗文集
（25 首）拆成 **252 行可以单独成句的句子**，每句带着它出自哪首诗。落一句话时随机抽一句，
尾句署名 `——《雁南情》` 这样的诗题。同名的句子不会连着出现两次。

诗集为空时（比如你清空了），才会退回内置的小生成器：

1. 先看现在几点——深夜、清晨、下午、黄昏、凌晨，用不同的一组词。
2. 从一份手写的词库里取名词、动词、形容词：灯、渡口、旧信、铁轨、井、潮汐、沉默、回声……
3. 套进句式模板：`{物}把{另一种东西}{动词}成了{结果}`、`{时间里}，{物}还在{地点}`、`没有{物}，只有{物}在{动词}`……
4. 去掉重复字太多的组合，输出两行：一行主句，一行尾句。

所以同一朵云，早上和深夜落下的句子不一样。它不聪明，只是安静。

## 颜色

诗集面板底部有一排色点：金 / 青 / 紫 / 粉 / 绿 / 白。选中的颜色会同时影响云的描边、诗句的尾句、
「留」按钮、面板边框和滚动条。选择存在本地，下次打开还是它。

实现上所有强调色都走两个 CSS 变量：`--pr-accent`（rgb 三元组，用于 `rgba()`）和
`--pr-accent-solid`（hex，用于纯色描边），组件根节点上注入，切换时不需要重建样式。

## 给别人用 / 上架

`plugins/PUBLISH.md` 写了完整路径：改包名 → `npm publish` → 写一个插件索引 JSON →
挂到 Discover 的 **Add index source**。现在这个目录里已经有 `npm pack` 打好的
`local-poem-rain-1.3.0.tgz`（19.8 KB，8 个文件），发给别人让他 **Plugins → Add plugin** 装本地包也行。

## 拖动

按住云拖动（`pointerdown/move/up` + `setPointerCapture`），移出 4 px 才算拖动，松手写进本地存储。
位置被夹在视口内：`x ∈ [6, innerWidth-40]`、`y ∈ [40, innerHeight-44]`，所以拖不出屏幕。
拖动结束后紧接着的那次 click 会被吞掉，不会顺带落一句诗。

## 边界

- 诗集只存在**这台机器的浏览器本地存储**里。换浏览器、清缓存都会丢；不会同步，也不会上传。
- 生成器是有限词库 + 模板，句子会有重复感。这不是模型写诗，是**规则下雨**。
- 组件挂在窗口的 overlay 图层上（`shell.overlay`），不占布局空间；它不会挡住编辑器，云本身只有 26 px。
- 不做分享、不做导出、不做账号。
